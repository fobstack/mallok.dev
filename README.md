# mallok.dev

The official website of [Mallok](https://github.com/fobstack/mallok), the
Cloudflare-native CMS. English and Simplified Chinese (`/zh-cn/`).

Plain static HTML and CSS generated by a small Python script (standard library
only), plus one short script for the theme toggle and header menus. Served
from Cloudflare Workers Static Assets.

## Layout

| Path | What |
| --- | --- |
| `src/` | Page generator: `build.py`, one module per page, `layout.py`, `tokens.py` (colour tokens, with an AA contrast check), `check.py` (structural checks) |
| `public/` | Everything that is served. HTML pages are **generated**; edit `src/`, not the HTML. `public/assets/` holds the hand-written CSS/JS, fonts and the brand kit |
| `public/design/` | The UI-language design board the site was built from |
| `redirect/` | A tiny Worker that 301s `www.mallok.dev` to `mallok.dev` |
| `NOTES.md` | Design notes and decisions |

## Build and check

```sh
python3 src/build.py
python3 src/check.py
python3 -m http.server 4400 --directory public
```

`src/fetch_fonts.py` downloads Figtree (SIL OFL 1.1) into
`public/assets/fonts/`; the files are already committed.

## Deploy

Needs `npx wrangler@4.166.0 login` with an account that has the `mallok.dev`
zone.

```sh
npx wrangler@4.166.0 deploy                 # mallok.dev
(cd redirect && npx wrangler@4.166.0 deploy) # www.mallok.dev -> mallok.dev
```

## Keeping the copy accurate

Every claim on the site (release status, CPU measurements, cost ladder,
commands) comes from the Mallok repository's `README.md` and `docs/`
(`RELEASE_STATUS.md`, `PRODUCT_VISION.md`). When those change, update the
pages here.
