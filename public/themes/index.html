ThemesFive bundled designs

Themes decide how it looks. Your content stays put.

Mallok ships five Liquid themes. Each one is a directory of templates and one stylesheet in your project, bundled into the Worker when you deploy. Pick one, adjust its options in the admin, or write your own.

02Switching themes

One line of source, one redeploy. Not one click.

The theme is a build-time choice in your site's Worker entry. Changing it means editing that line, building and deploying — and Mallok's admin says so rather than offering a switch that pretends otherwise.

  • No content is migrated, no content id changes, and by default no public URL changes.
  • A content kind the new theme does not declare is rendered through its page layout; the content and its URLs stay.
  • The options a theme exposes — headlines, colours, links — are edited in the admin and are live immediately.
  • Templates ship inside the Worker and assets go to Static Assets; a theme is never stored in D1 or R2.

03Writing a theme

Declarative by design, checkable at build time.

Third-party themes use the same documented contract as the bundled ones. There is no private interface only official themes can reach.

theme.json

Declares the theme's content kinds, their fields, the options it exposes to the admin, its language packs and any client script.

Restricted Liquid

Layouts and partials in a restricted Liquid subset, rendering a documented view object. No arbitrary JavaScript runs in a theme.

Distributed as source

Copy a theme directory into your project or start from a starter. It enters your build artifact, so review it as you would any code you ship.

Read the theme format

One command. Your account. Your content.

Mallok creates a Worker, a D1 database and an R2 bucket in your own Cloudflare account and deploys the site there. Nothing is hosted by Mallok, and there is no Mallok account to open.

npx mallok create my-site

Needs Node.js 22+ and wrangler login. Add --no-deploy to generate and check a project locally without creating cloud resources. Currently a 0.1 release candidate.
