01品牌概念

一条不间断的引线，一个穿梭的圆点。

首字母 M 由一条连续不间断的交织引线构成，象征运行于 Cloudflare Workers + D1 + R2 上的无服务器无缝流转。右下角唯一的「穿梭青」圆点，与字标中双轨流线的 ll 遥相呼应。

它们合在一起，讲的就是产品的故事：不用运维、内容即时编织上线、Markdown 自由不锁定。

04使用规范

怎么用，以及不能碰的红线。

正确用法

  • 安全留白：标志四周的最小安全间距，不小于「穿梭圆点」的 1 倍直径。
  • 最小尺寸：完整横版标志在屏幕上最小宽度 96 px；独立图形最小 16×16 px。
  • 16–32 px 务必使用 favicon 套件中针对小尺寸优化的版本。
  • 按背景选文件：浅色底用彩色浅底版或单色浅底版；深色底用彩色深底版、强调色版或单色深底版。
  • 穿梭青是唯一的故事强调色：只用于穿梭圆点、双 l 亮点和“即时”状态提示，克制使用。

禁止操作

  • 不要给独立 M 图形加圆角方框或其他底托。仅 iOS / Android App 图标除外。
  • 不要拉伸、变形。
  • 不要自行更改穿梭青与交织紫的配色比例，也不要改色。
  • 不要在浅色背景上用穿梭青（#06B6D4）或 #0D9488 写小字，它们在浅底上的对比度不到 4.5:1。本站的青色文字使用 --live（#0f766e）。

07界面语言

Logo 怎样变成界面。

丝带变成连接卡片和流程节点的引线；圆头线端变成胶囊按钮和圆角卡片；穿梭圆点用来标记状态、列表项和当前页面；字标里的双 l 变成成对的东西：两条时间线、EN 与中文。

80% 中性 · 云端白 / 暗夜深15% 紫

80% 中性色；15% 交织紫，用于动作和引线；5% 穿梭青，只讲一个故事：即时、已上线、已到达。青色不做第二种按钮色。

08字体

西文用 Figtree，中文和代码用系统字体。

Figtree 的 800 字重和字标那种很粗的几何小写最接近，400 字重读正文也舒服。字体文件尚未放入 /assets/fonts/，所以当前构建显示的是系统回退字体；无论哪种情况都不向第三方发请求。中文使用苹方、微软雅黑和思源黑体，代码使用各平台自带的等宽字体，两者都不加载网络字体。

一条命令，部署到你自己的账号。

Mallok 会在你自己的 Cloudflare 账号里创建 Worker、D1 数据库和 R2 存储桶，并把网站部署上去。Mallok 不托管任何东西，也不需要注册 Mallok 账号。

npx mallok create my-site

需要 Node.js 22 及以上，并先执行 wrangler login。加上 --no-deploy 只在本地生成并检查项目，不创建云资源。当前为 0.1 候选版。
