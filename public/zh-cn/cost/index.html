CostCloudflare 成本阶梯

从免费额度起步。只有一级付费台阶，而且别的都不用改。

Mallok 本身免费、开源，也不托管任何东西：所有费用都由你自己的账号直接付给 Cloudflare（如果发邮件，还有 Resend）。Mallok 以 Cloudflare 免费额度起步为设计目标——这是设计目标，不是无限免费的承诺。

01两级台阶

先免费；有量之后，每个账号每月 5 美元。

Mallok 依赖的每一项 Cloudflare 产品都有免费额度。唯一的付费台阶是 Workers Paid：它只是提高同一个 Worker、同一个 D1 数据库、同一个 R2 存储桶的上限——不迁移数据，也不改架构。

第 0 级 $0 付给 Cloudflare

免费额度

每天 10 万次 Worker 请求（每次 10 ms CPU）、5 GB D1、10 GB R2、免费的缓存与清除、每账号 5 个定时触发器、Turnstile 和 DNS。域名仍然需要，而域名不是免费的。

第 1 级 $5 / 月 / 账号

Workers Paid

每月 1000 万次请求、3000 万 CPU 毫秒，单次调用默认 30 秒 CPU，D1 上限大幅提高，定时触发器增至 250 个。按 Cloudflare 账号计费，账号下的所有站点共用。超出包含额度的用量由 Cloudflare 另行计费。

03影响产品设计的几条限制

免费额度有边界，位置在这里。

每个账号 5 个定时触发器

每个 Mallok 站点用一个定时触发器来处理定时发布和邮件重试。所以一个免费 Cloudflare 账号最多支撑 5 个站点的定时任务；站点更多就需要 Workers Paid。

D1 的每日上限是硬限制

超过 D1 免费的每日行数后，数据库当天剩余时间都不可用，所有依赖 D1 的事情——冷渲染、保存、询盘——也随之停摆。站点长大后要留意用量。

免费套餐的 10 ms CPU

rc.5 实测缓存命中为 0–1 ms CPU；冷渲染 p50 为 11 ms、p95 为 35 ms，30 个样本里有 16 个超过 10 ms 目标，该样本中没有请求失败。这是候选版的已知限制，而且 rc.5 的数据不能代表之后的候选版。 发布状态

缓存需要自定义域名

边缘缓存——也就是让绝大多数请求不占用 Worker CPU 额度的关键——需要自定义域名才能工作。workers.dev 地址只用于预览。请把域名算进预算；Cloudflare Registrar 按成本价出售域名。

04有意不用的服务

为了让台阶少一些，Mallok 不用这些。

免费额度太紧或没有免费额度的依赖，都会多出一级付费台阶。所以 Worker 只用 D1、R2、Static Assets、Cache API 和一个定时触发器，别的都不用。

Workers KV免费额度每天只有 1000 次写入
Cloudflare Images付费——改为在浏览器里处理图片
Email Workers send仅 Paid 可用，且只能发到已验证地址
Queues不需要——定时任务已覆盖邮件重试
Durable Objects不使用

05哪些不免费

把账算清楚。

域名

缓存需要它，一个像样的企业官网也需要它。价格由注册商决定。

大量邮件

询盘邮件通过 Resend 发送。免费额度每月 3000 封、每天 100 封，超出需要 Resend 的付费套餐。

你的时间

安装需要一个会用 Node 和终端的人。主题、插件和升级的重新部署，也要这个人来做。

一条命令，部署到你自己的账号。

Mallok 会在你自己的 Cloudflare 账号里创建 Worker、D1 数据库和 R2 存储桶，并把网站部署上去。Mallok 不托管任何东西，也不需要注册 Mallok 账号。

npx mallok create my-site

需要 Node.js 22 及以上，并先执行 wrangler login。加上 --no-deploy 只在本地生成并检查项目，不创建云资源。当前为 0.1 候选版。
