Themes内置五套设计

主题决定外观，内容原地不动。

Mallok 自带五套 Liquid 主题。每套主题就是项目里的一个模板目录加一份样式表，部署时打包进 Worker。选一套，在后台调整它的选项，或者自己写一套。

02切换主题

改一行源码，重新部署一次。不是点一下就行。

主题是站点 Worker 入口里的构建期选择。更换主题就是改这一行，然后构建、部署——Mallok 的后台会如实告知，而不是放一个假装能热切换的开关。

  • 不迁移内容，不改内容 id，默认也不改任何公开 URL。
  • 新主题没有声明的内容类型，会用它的页面布局渲染；内容和 URL 都保留。
  • 主题开放的选项——标题、颜色、链接——在后台修改，立即生效。
  • 模板随 Worker 打包，静态资源交给 Static Assets；主题不会存进 D1 或 R2。
改这一行构建部署新外观，URL 不变

03编写主题

声明式设计，构建时即可校验。

第三方主题和内置主题用的是同一份公开的约定，不存在只有官方主题才能用的私有接口。

theme.json

声明主题的内容类型及其字段、开放给后台的选项、语言包，以及用到的客户端脚本。

受限的 Liquid

布局和局部模板使用受限的 Liquid 子集，渲染一份有文档的视图对象。主题里不会运行任意 JavaScript。

以源码分发

把主题目录复制进项目，或从 starter 开始。它会进入你的构建产物，所以请像审查其他上线代码一样审查它。

阅读主题格式文档（英文）

一条命令，部署到你自己的账号。

Mallok 会在你自己的 Cloudflare 账号里创建 Worker、D1 数据库和 R2 存储桶，并把网站部署上去。Mallok 不托管任何东西，也不需要注册 Mallok 账号。

npx mallok create my-site

需要 Node.js 22 及以上，并先执行 wrangler login。加上 --no-deploy 只在本地生成并检查项目，不创建云资源。当前为 0.1 候选版。
