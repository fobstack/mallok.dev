A · 引线 Thread

轻、亮、圆；一条线把内容从 Markdown 串到上线的页面

怎么从 Logo 来的

  • 丝带 → 线：一条波浪线把卡片、流程节点串起来；首屏里它连接「编辑器」和「上线的页面」，从紫渐变到青。
  • 圆头线端 → 圆角：按钮、徽标、命令条全是胶囊形，卡片 20–24px 圆角。
  • 穿梭圆点 → 标记：状态点、列表符号、当前导航、流程终点，都是同一颗青色圆点；首屏里它沿着引线移动。
  • 双 l → 成对：两条时间线之间一对青色竖波纹；EN / 中文是一对胶囊，多语言演示就是这一对的放大。
  • 折叠阴影 → 层次：卡片底部一道很淡的紫色渐变加柔和紫调投影。
  • 粗几何小写 → 标题：Figtree 800，负字距。

取舍

  • 颜色按 80 / 15 / 5 分配：中性色为主，紫色只做动作和线，青色只讲「即时上线」。
  • 原来的方向 B 不再单独展示。它的两样东西并进了 A，用在信息密集的页面：平行轨道的时间线、只有发丝线的表格（见第 10 节）。
  • 代价：圆角和投影多，信息密度偏低，所以成本页、文档页改用密集变体。
  • 所有文案都对照文档核对过；没有对比表、没有速度数字、没有「一键部署」。

0.1 候选版 —— rc.10

为多语言 B2B 网站而生的 Cloudflare 原生 CMS

Mallok 是开源的 WordPress / Ghost 替代方案：Markdown 内容、网页后台、Liquid 主题和询盘表单，一并部署到你自己的 Cloudflare 账号。不用维护服务器，发布内容也不用重新构建。

开始使用→查看在线演示
$npx mallok create my-site

需要 Node.js 22 及以上，并先执行 wrangler login。会在你的 Cloudflare 账号里创建资源并完成部署。

保存 → 一次 D1 写入 + 一次按标签清缓存 → 上线，不需要构建。清除边缘缓存需要自定义域名和清缓存令牌；没有令牌时，访客要等缓存过期才能看到新内容。示例内容仅作演示，企业与产品均为虚构。

  • 主题页面不带客户端 JS*
  • 多语言 + 自动 hreflang
  • 从 Cloudflare 免费额度起步（并非无限）
  • Apache-2.0 开源

* 例外：询盘表单的 Turnstile 脚本，以及 Atelier 首页声明的一个轮播脚本。你启用的 Cloudflare 功能可能会注入它们自己的脚本。

3 · 功能区：三个承诺

浅色

01What is Mallok?

A CMS's editing, an edge network's delivery, and content you can take with you.

Mallok is built on three promises that refuse both prices.

01No operations

No server to run

There is no host to patch and no database server to keep alive. Mallok is one Worker in your own Cloudflare account. Mallok hosts nothing, cannot reach your site, and has no account system to sign up for.

What gets created
One Worker, one D1 database, one R2 bucket

02No build for content

Edits are live immediately

Saving is one D1 write plus a precise cache purge by tag. No CI run, no build queue, no redeploy. The same goes for settings, theme options and plugin settings.

What it needs
A custom domain and a cache-purge token. Without the token, visitors see the previous version until the cache expires.

03No lock-in

Your content leaves as Markdown

D1 stores standard Markdown with YAML front matter; media sits in R2. Export produces ordinary bundles — index.md plus images/ — designed to re-import into a fresh Mallok site byte-identically.

Also exportable
Inquiries, as CSV

补充

字体与动效

字体：Figtree（只加载这一个家族）

  • 字标是很粗的几何小写，圆润、开口大、a 是双层。Figtree 的 800 / 900 字重和它的骨架最接近，400 字重读正文也舒服，一个可变字体文件就覆盖全部字重。
  • 画板从 Google Fonts 加载；正式站应当自托管 woff2（只子集拉丁字符，约 30 KB 以内），不向第三方发请求。
  • 回退栈：Figtree, ui-sans-serif, system-ui, -apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif。
  • 中文不加载网页字体，直接用 PingFang SC / Microsoft YaHei / Noto Sans SC。中文标题用系统最粗的一档（PingFang Semibold），字距归零，行高放到 1.25–1.3。
  • 等宽：ui-monospace, "SF Mono", Menlo, Consolas, monospace，系统字体，不加载。

动效（纯 CSS，正式站不带 JS）

  • 圆点呼吸：徽标前的状态点 2.4s 一次的光晕扩散（画板里已实现）。
  • 圆点穿梭：首屏引线上的圆点用 offset-path 从编辑器走到页面，3.6s 一次（画板里已实现）。
  • 引线描画：流程图的线用 stroke-dashoffset 在载入时从左画到右，600ms，一次（正式站再做）。
  • 按钮：悬停 150ms 换色，箭头右移 3px；按下回弹 1px。
  • 卡片：悬停上浮 2px，投影加深。
  • 分段开关、展开节点：单选按钮和 <details>，状态切换不加动画，保证键盘操作即时。
  • 命令条：user-select: all，点一下全选，不需要「复制」脚本。
  • 全部包在 prefers-reduced-motion: no-preference 里；减少动效时一律静止。时长 150 / 240 / 600ms，缓动 cubic-bezier(.2,.7,.2,1)。
